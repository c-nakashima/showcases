# Frontend Mentor Challenge Star Rating Component

## Demo
A star rating component using React + Vite as part of a Frontend Pro challenge.
This mini project was a good training to focus on clean component design and UI fundamentals with a given challange and constraint.

What I focused on:
- Keeping the React component structure simple and reusable
- Clear state & props responsibility
- Writing maintainable CSS with BEM-style naming
